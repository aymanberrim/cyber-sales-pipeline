# 6 · Close

**Input:** a booked, qualified scoping call.
**Output:** a signed paid pilot (continuous testing + hardening), earned off a scoped red-team.
**Exit criterion:** red-team delivered with a written report; pilot scoped with success criteria both sides agreed.
**Metric:** red-team-to-pilot conversion; time-to-pilot.

## The wedge: a scoped, free (or low-cost) red-team of one agent

Not a feature tour — a demonstration of the vendor's own product on the prospect's reality. Pick the one agent and the one vulnerability class the stack exposes (from [`plays/agent-attack-surface-mapping.md`](../plays/agent-attack-surface-mapping.md)), run the attack, and deliver:

- **what we tried** — concrete attacks, not a scanner dump;
- **what landed** — the breach, reproducible, with severity;
- **what it would cost them** — data exposed, action taken, policy broken;
- **how to harden it** — measurable, and the gap the vendor's continuous monitoring closes.

A real breach in a report sells the pilot on its own. A clean result is also a win: it is proof in writing, and the monitoring keeps it clean as the agent changes.

## From red-team to pilot

The pilot is continuous: attack simulations on a cadence, runtime monitoring, hardening as the agent evolves. Scope it with success criteria the champion can defend internally (agents covered, attack classes, reporting rhythm). In enterprise, the champion carries this to the CISO with the red-team report as the business case.

## Handoff

A signed pilot goes to **7 · Learn**: feed what converted — and what the red-team found — back into targeting and the message angles.
